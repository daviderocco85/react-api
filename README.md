# React API

Progetto React/Vite che utilizza chiamate API per mostrare in un'app liste di attori e attrici.

# Obiettivo

Creare un'app che mostri un elenco di attori o attrici.

## Milestone 1

Al caricamento dell'app, recuperare la lista degli attori e delle attrici dalle API e stamparli in console.

## Milestone 2

Preparare una card per ciascun attore/attrice, mostrandone le seguenti informazioni:

1. Nome
2. Anno nascita
3. Nazionalità
4. Biografia
5. Immagine dell'attore/attrice
6. Riconoscimenti

## Milestone 3

Mostrare in pagina una card per ciascun attore con layout customizzato.

## BONUS 1 

Stampare sia una lista delle attrici che degli attori, separatamente.

## BONUS 2 

Stampare un’unica lista che contiene attori e attrici insieme.

## BONUS 3 

Aggiungere nella card dell’attore/attrice i film più famosi.

## Note

Le API sono fornite dal master in Web Development.
